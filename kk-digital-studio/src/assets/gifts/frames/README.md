# KK Gifts frame image handoff

Generate one original product photograph for each filename below and keep the files local to this folder.

- `wooden-frame-heritage-01.webp` - walnut wooden portrait frame, 4:5
- `gold-frame-royal-01.webp` - champagne-gold wedding frame, 4:5
- `acrylic-frame-crystal-01.webp` - clear acrylic photo block, 4:5
- `canvas-frame-gallery-01.webp` - gallery canvas wrap, 3:2
- `metal-frame-ebony-01.webp` - matte black brushed-metal frame, 4:5
- `wooden-frame-collage-story-01.webp` - six-window walnut collage frame, 4:5

The complete prompt, negative prompt, visual-search keywords, and folder mapping are exported from `src/data/frameImagePrompts.js` and attached to each item in `src/data/frames.js` as `imageBrief`.

Google or competitor images are reference material only. Do not download or reuse them. Replace the current remote catalog references with local imports after the original renders pass the quality check.
